## About

A classic Tic-Tac-Toe game for two players, playable directly in the browser with
no dependencies. It started as a JavaScript school exercise and grew into a small,
polished game: it keeps a **running score**, detects wins and draws, and pops up a
prompt when someone wins so you can **play again or stop**.

## Features

- Two-player X/O gameplay on a 3×3 board
- Win and draw detection
- Persistent **score counter** across rounds
- "Play again?" prompt after each finished game
- Pure vanilla **HTML / CSS / JavaScript** — no build tools, no libraries

## Play it

```bash
git clone https://github.com/olivierluethy/Tic-Tac-Toe-in-JS.git
cd Tic-Tac-Toe-in-JS
```

Then open `index.html` in any modern browser — that's it.

## Project structure

```
index.html        Markup and board
style.css         Styling
index.js          Game logic (win/draw detection, score)
player_turn.js    Turn handling
```
